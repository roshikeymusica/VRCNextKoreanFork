How each number is obtained
Attribution model

Instrumented module bytes live inside the GC heap, so they are never added on top of it. Native probes live outside the GC heap, so they are subtracted from the non-GC part of the process commit.

managed unattributed = GC heap − Σ instrumented module bytes
native  unattributed = process private − GC committed − Σ native probes

Anything the instrumentation does not cover stays in the unattributed buckets. Those buckets are never distributed across modules.
